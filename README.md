# **Website Traffic Analysis 📊**

## **About the Project**

This project analyzes **website traffic data** to understand **user activity, website events, traffic trends, countries, cities, and links**.

## **Tools Used**

- **Python**
- **Pandas**
- **NumPy**
- **Matplotlib**
- **Seaborn**
- **Jupyter Notebook**

## **Analysis**

- **Data Cleaning**
- **Missing Value Analysis**
- **Duplicate Data Removal**
- **Date Analysis**
- **Event Analysis**
- **Daily Traffic Analysis**
- **Country Analysis**
- **City Analysis**
- **Link Analysis**
- **Data Visualization**

## **Dataset**

The dataset contains **website traffic/event information** such as:

- **Event**
- **Date**
- **Country**
- **City**
- **Artist**
- **Album**
- **Track**
- **ISRC**
- **Link ID**

## **Key Metrics**

- **Total Events:** 122,567
- **Unique Links:** 3,839
- **Unique Countries:** 211
- **Unique Cities:** 11,993

## **Data Cleaning**

- Checked for **missing values**
- Identified **duplicate rows**
- Removed **103,711 duplicate rows**
- Converted the **date column** into datetime format
- Final dataset contains **122,567 rows**

## **Visualizations**

The project includes visualizations for:

- **Website Events**
- **Daily Traffic**
- **Traffic Patterns**
- **User Activity**

## **Goal**

The main goal is to **analyze website traffic data and identify useful patterns in user activity and website interactions**.

## **Conclusion**

This analysis provides an overview of **website activity, traffic trends, popular events, links, countries, and cities**.
